# Item Value Tracker

Personal web app for tracking what items cost, what extra money went into them, what they are worth now, and what you recover when selling.

## MVP
- Mobile-first dashboard
- Item purchase and extra-cost tracking
- Market-value override
- Straight-line and declining-balance estimates
- Recovery percentage and depreciation
- PostgreSQL via Prisma
- Next.js App Router
- Railway deployment

This is a resale/value tracker, not accounting or tax depreciation software.

Production deployment configured with Railway and PostgreSQL.
